# Алиас

Командная игра «объясни слово, не называя его» для телефона. Одна страница без сборки и без сервера: работает офлайн и устанавливается как приложение (PWA).

## Возможности

- От 2 до 6 команд, у каждой свой словарь.
- Время на ход и очки для победы выбираются кнопками или вводятся вручную (10–600 с, 5–500 очков).
- Свайп вверх — «угадали», вниз — «пропуск». На компьютере стрелки ↑/↓ и пробел.
- Штраф за пропуск можно отключить.
- «Последнее слово»: после конца времени его может угадать любая команда.
- В итогах хода можно исправить результат любого слова.
- Слова не повторяются между партиями, пока не выпадет весь словарь. История хранится в браузере, сбросить её можно в настройках.
- Игра сохраняется в браузере: после перезагрузки её можно продолжить.

| Словарь | Слов | Где лежит |
|---|---|---|
| Базовый (по умолчанию) | 4252 | `words-base.js` |

| Детский (10–14 лет) | 203 | `index.html` |
| Лёгкий / Средний / Сложный | 136 / 138 / 112 | `index.html` |
| Новогодний | 150 | `index.html` |
| Наука | 164 | `index.html` |
| Микс (лёгкий, средний и сложный вперемешку) | — | — |

Форматы:

- **Русские словари:** слова через пробел, `_` означает пробел внутри фразы (`летучая_мышь`).
- **Английский:** по одной строке `word=перевод`.

## Запуск

Откройте `index.html` в браузере. Чтобы игру можно было установить как приложение и играть без интернета, её нужно открывать с сайта по https: браузер не регистрирует service worker для страницы, открытой как файл.

### GitHub Pages

1. Загрузите файлы в корень репозитория.
2. Откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.

Для проверки на своём компьютере:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Файлы

```
index.html            игра: разметка, стили, логика, небольшие словари
words-base.js         базовый словарь
words-en.js           английский словарь с переводами
manifest.json         описание приложения для установки
sw.js                 service worker: офлайн-кэш
icon-*.png, apple-touch-icon.png, favicon-32.png   иконки
```

## При изменениях

После любой правки файлов увеличьте номер кэша в `sw.js` (`const CACHE = PREFIX + 'N'`). Тогда у тех, кто уже установил приложение, загрузится новая версия. Если добавляете новый файл, впишите его и в список `CORE` в `sw.js`.
